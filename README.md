# WK CRM — каталог запчастей, база знаний, запасы, обеспеченность, закупки и ремонты экскаваторов WK

Оффлайн-каталог: вся логика в браузере, данные — статичные файлы в `data/`.
Подробный план, источники и открытые вопросы — [`PLAN.md`](PLAN.md).
Актуальный статус ветки **grok** — [`STATUS.md`](STATUS.md).

## Ветки репозитория

| Ветка | Содержимое |
|-------|------------|
| **`grok`** | текущая рабочая ветка портала: те же витрины, что у GBT, плюс роли, ссылки с состоянием, палитра поиска, пакет «заказать сегодня», ленивая загрузка |
| **`GBT` / `catalog-crm`** | исходный портал (index.html, app.js, data/, lib/) плюс библиотека знаний (`media/kb/`, 2,8 ГБ) |
| **`main`** | прайс-листы ДП/УСО (исходники для сборки) |
| **`rawdata`** | ведомость взаимозаменяемости, книги LinkOme, исходники базы знаний АТ-Майнинг |

Репозиторий приватный — прайсы поставщика коммерческая информация.

## Как открыть

**1. Скачать и открыть на компьютере, без интернета.** Скачайте ветку
`grok` или `catalog-crm` целиком, распакуйте и откройте `index.html`.
Сервер не нужен: данные в `data/*.local.js` грузятся тегом `<script>`.

**2. GitHub Pages.** Workflow (`.github/workflows/pages.yml`) срабатывает
на `grok`, `GBT` и `catalog-crm`. Публикуются портал, график план-факта
и чертежи LinkOne. Библиотека знаний (`media/kb/`) на Pages не едет.

Ссылку на конкретный вид можно копировать из шапки: хэш хранит вкладку,
роль, площадку, машину, заказ, ЕКМТР и каталожный номер.

## Сборка данных

Все `data/*.json`/`data/*.local.js` собираются скриптами `build/*.py` —
см. [`build/README.md`](build/README.md).

## Проверка целостности

```
python3 -m unittest discover -s tests
node --test tests/*.mjs
python3 tests/audit_data.py
node --check app.js schedule.js
```
