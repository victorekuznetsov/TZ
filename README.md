# WK CRM — каталог запчастей, база знаний, запасы, обеспеченность, закупки и ремонты экскаваторов WK

Оффлайн-каталог: вся логика в браузере, данные — статичные файлы в `data/`.
Подробный план, источники и открытые вопросы — [`PLAN.md`](PLAN.md).

## Ветки репозитория

| Ветка | Содержимое |
|-------|------------|
| **`catalog-crm`** | сам портал (`index.html`, `app.js`, `styles.css`, `data/`, `lib/`) плюс полная библиотека знаний (`media/kb/`, 2,8 ГБ) — эта ветка |
| **`main`** | прайс-листы ДП/УСО (исходники для сборки) |
| **`rawdata`** | ведомость взаимозаменяемости, книги LinkOme, исходники базы знаний АТ-Майнинг — сырьё для сборки, само по себе не открывается |

Репозиторий приватный — прайсы поставщика коммерческая информация.

## Как открыть

**1. Скачать и открыть на компьютере, без интернета.** Скачайте ветку
`catalog-crm` целиком (Code → Download ZIP, или `git clone -b catalog-crm`),
распакуйте и откройте `index.html` двойным щелчком — сервер не нужен.
Данные лежат в `data/*.local.js`, а не в голом JSON: браузер блокирует
`fetch()` локального файла при открытии без сервера, а тег `<script>` —
нет (см. `build/README.md`). Работает весь функционал полностью локально:
каталог, аналитика (запасы, обеспеченность, закупки, ремонты, парк),
LinkOne-каталог, полнотекстовый поиск по базе знаний — и сами файлы базы
знаний (`media/kb/`, 936 документов, 2,8 ГБ — PDF, DOC/DOCX, чертежи DWG,
открываются кликом «файл» без интернета), и браузерная пересборка остатков
на вкладке «Обновление данных». Из-за библиотеки знаний скачивание тяжёлое
(~2,8 ГБ) — это плата за то, что после скачивания ничего больше не нужно.

**2. GitHub Pages.** Деплоится автоматически при пуше в `catalog-crm`
(`.github/workflows/pages.yml`) — публикуются только файлы самого портала
(`index.html`, `app.js`, `styles.css`, `data/`, `lib/`), не библиотека
знаний (`media/`, слишком тяжело для Pages), не прайсы и не сборочные
скрипты. На Pages ссылки «файл» в базе знаний не работают — только у
локально скачанной копии. Нужно один раз включить в Settings → Pages →
Build and deployment → Source → **GitHub Actions**. Приватный репозиторий —
сайт доступен так же, как сам репозиторий (нужен план GitHub, поддерживающий
Pages для приватных репозиториев).

## Сборка данных

Все `data/*.json`/`data/*.local.js` собираются из исходников скриптами
`build/*.py` — см. [`build/README.md`](build/README.md).

## Проверка целостности

После обновления данных выполните `python tests/audit_data.py`. Проверка
контролирует витрины, уникальность ключей, связи каталога и наличие файлов.
Отчёт ветки GBT — [`GBT_AUDIT.md`](GBT_AUDIT.md).
