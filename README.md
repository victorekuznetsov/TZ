# WK CRM — каталог запчастей, база знаний, запасы, обеспеченность, закупки и ремонты экскаваторов WK

Оффлайн-каталог: вся логика в браузере, данные — статичные файлы в `data/`.
Подробный план, источники и открытые вопросы — [`PLAN.md`](PLAN.md).

## Ветки репозитория

| Ветка | Содержимое |
|-------|------------|
| **`catalog-crm`** | сам портал (`index.html`, `app.js`, `styles.css`, `data/`, `lib/`) — эта ветка |
| **`main`** | прайс-листы ДП/УСО (исходники для сборки) |
| **`rawdata`** | ведомость взаимозаменяемости, книги LinkOme, база знаний АТ-Майнинг — сырьё, не деплоится |

Репозиторий приватный — прайсы поставщика коммерческая информация.

## Как открыть

**1. Скачать и открыть на компьютере, без интернета.** Скачайте ветку
`catalog-crm` целиком (Code → Download ZIP, или `git clone -b catalog-crm`),
распакуйте и откройте `index.html` двойным щелчком — сервер не нужен.
Данные лежат в `data/*.local.js`, а не в голом JSON: браузер блокирует
`fetch()` локального файла при открытии без сервера, а тег `<script>` —
нет (см. `build/README.md`). Работает весь функционал, включая полнотекстовый
поиск по базе знаний и браузерную пересборку остатков на вкладке «Обновление
данных».

**2. GitHub Pages.** Деплоится автоматически при пуше в `catalog-crm`
(`.github/workflows/pages.yml`) — публикуются только файлы самого портала
(`index.html`, `app.js`, `styles.css`, `data/`, `lib/`), не прайсы и не
сборочные скрипты. Нужно один раз включить в Settings → Pages → Build and
deployment → Source → **GitHub Actions**. Приватный репозиторий — сайт
доступен так же, как сам репозиторий (нужен план GitHub, поддерживающий
Pages для приватных репозиториев).

## Сборка данных

Все `data/*.json`/`data/*.local.js` собираются из исходников скриптами
`build/*.py` — см. [`build/README.md`](build/README.md).
